## Spell Durability Gate (Spell Engine Add-On)

An add-on for Spell Engine that stops you from casting spells with broken items.

Useful when using Spell Engine with mods that prevent items from breaking, but make them useless at 0 durability.

Built on the fantastic Spell Engine by Daedelus.

### Version
Latest version works with Spell Engine 1.10.9 for Neoforge 1.21.1.
